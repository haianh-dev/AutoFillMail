# 04 — Tech Plan

## 1. Stack
- **HTML + CSS + JavaScript thuần (ES2020, script cổ điển)**. Không framework, không bundler, không `npm install`.
- Node ≥ 18 chỉ để chạy 2 script: `build-templates.mjs` và `verify.mjs`.
- Chạy app: double-click `app/index.html` (`file://`).

Lý do: `fetch()` file local và `<script type="module">` bị trình duyệt chặn trên `file://`. Nên template được **nhúng sẵn vào 1 file JS cổ điển** bằng script build.

## 3. `scripts/build-templates.mjs`
- Đọc 3 file UTF-8 trong `templates/`: `kmdh`, `nvtch`, `dsnh`.
- Ghi `app/templates.generated.js` với nội dung:
  ```js
  /* AUTO-GENERATED by scripts/build-templates.mjs — DO NOT EDIT */
  window.SH27_TEMPLATES = { kmdh: "…", nvtch: "…", dsnh: "…" };
  ```
  Dùng `JSON.stringify(content)` cho từng template (đảm bảo giữ nguyên từng ký tự, `\n` giữ nguyên, tiếng Việt giữ UTF-8). Ghi file bằng `utf8`, không BOM.
- In ra kích thước từng template và checksum SHA-256 ngắn (8 ký tự đầu) để dễ đối chiếu.
- Thoát mã ≠ 0 nếu thiếu file.

## 4. `app/fill.js` — lõi (hàm thuần, không đụng DOM)

Xuất theo kiểu dùng được 2 nơi:
```js
(function (root, factory) {
  const api = factory();
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
  else root.SH27Fill = api;
})(typeof self !== 'undefined' ? self : this, function () {
  /* … */
  return { PLACEHOLDER_RE, normalizeText, escapeHtml, deriveDemTen,
           formatDate, slugify, validate, isSentenceStart, replaceTokens, fill, findLeftovers };
});
```

Hàm cần có:

| Hàm | Mô tả |
|---|---|
| `normalizeText(s)` | `trim()` + gộp whitespace liên tiếp thành 1 dấu cách |
| `escapeHtml(s)` | theo docs/03 §5 |
| `deriveDemTen(hoTen)` | tách theo whitespace; ≥2 từ → 2 từ cuối; 1 từ → chính nó; rỗng → `''` |
| `formatDate(iso)` | `'2026-11-15'` → `'15/11/2026'`; không hợp lệ → `''` |
| `slugify(s)` | theo FR-3 |
| `validate(values)` | trả `{ ok, errors: { key: 'Vui lòng nhập …' } }` |
| `isSentenceStart(before)` | theo docs/03 §4.2: token có đứng đầu câu không (quyết định `Anh` hay `anh`) |
| `replaceTokens(tpl, resolver)` | cấp thấp: single-pass regex, gọi `resolver(key, ctx)` với `ctx = { before }` (≤200 ký tự **gốc** của template ngay trước token); dùng cho test byte-identical |
| `fill(templateHtml, values)` | chuẩn hoá + escape giá trị rồi gọi `replaceTokens`, trả chuỗi HTML mới |
| `findLeftovers(html)` | trả mảng chuỗi placeholder còn sót (docs/03 §3) |

### Thuật toán (tham chiếu)
```js
const KEY_BY_PREFIX = [
  ['[Lĩnh', 'linhVuc'], ['[Nghệ', 'ngheDanh'], ['[Anh/Chị]', 'xungHo'],
  ['[đệm', 'demTen'],   ['[Họ', 'hoTen'],      ['...', 'ngay'],
];
function replaceTokens(tpl, resolver) {
  // callback của String.replace nhận (match, ...groups, offset, wholeString)
  return tpl.replace(PLACEHOLDER_RE, (m, ...rest) => {
    const offset = rest[rest.length - 2];
    const before = tpl.slice(Math.max(0, offset - 200), offset);
    const hit = KEY_BY_PREFIX.find(([p]) => m.startsWith(p));
    return resolver(hit[1], { before });
  });
}
function fill(tpl, v) {
  const xung = v.xungHo === 'chị' ? 'chị' : 'anh';
  const cap = (w) => w.charAt(0).toUpperCase() + w.slice(1);
  const val = {
    linhVuc:  escapeHtml(normalizeText(v.linhVuc)),
    ngheDanh: escapeHtml(normalizeText(v.ngheDanh)),
    demTen:   escapeHtml(normalizeText(v.demTen)),
    hoTen:    escapeHtml(normalizeText(v.hoTen)),   // token P5 đã gồm dấu "." → dấu chấm bị bỏ
    ngay:     formatDate(v.ngay),
  };
  return replaceTokens(tpl, (key, ctx) =>
    key === 'xungHo' ? (isSentenceStart(ctx.before) ? cap(xung) : xung) : val[key]);
}
```
`fill` **không** được thêm/bớt/đổi bất cứ thứ gì khác.

## 5. `app/app.js` — UI logic
- Trạng thái: `values` (7 key ở docs/02) + cờ `demTenTouched`.
- Khi input đổi: cập nhật `values` → nếu `!demTenTouched` thì `demTen = deriveDemTen(hoTen)` → debounce 150 ms → `render()`.
- `render()`:
  1. `tpl = window.SH27_TEMPLATES[values.type]`
  2. `html = SH27Fill.fill(tpl, values)`
  3. Gán `iframe.srcdoc = html` (iframe `sandbox="allow-popups allow-popups-to-escape-sandbox"`; **không** cho chạy script).
  4. `validate` + `findLeftovers` → bật/tắt nút Tải/Sao chép, hiện lỗi từng ô.
- Tải về: `new Blob([html], {type:'text/html;charset=utf-8'})` → `URL.createObjectURL` → thẻ `<a download>` → click → `revokeObjectURL`.
- Sao chép: xem FR-4.
- `localStorage` theo FR-6, luôn bọc `try/catch`.
- Nếu `window.SH27_TEMPLATES` chưa có (quên build) → hiện thông báo lớn: "Chưa build template. Chạy: node scripts/build-templates.mjs".
